# 부스터 페달 배치 위치에 따른 사운드 차이

> [!abstract] 요약
> 부스터를 드라이브 **뒷단**에 두면 클리핑된 신호의 진폭만 증폭되어 순수 볼륨 부스트, **앞단**에 두면 드라이브 회로 입력을 밀어 게인·서스틴·컴프레션이 증가.

## 배경 / 원리

- 부스터 = 신호 진폭(전압 스윙)을 증폭하는 게인 스테이지
- 드라이브 페달의 왜곡 = 입력 신호가 클리핑 임계 전압을 초과할 때 파형 상·하단이 깎이는 현상 → **입력 레벨이 클수록 클리핑 구간 증가**
- 따라서 부스터가 클리핑 회로 **앞**에 있는가 **뒤**에 있는가에 따라, 같은 부스터라도 결과가 근본적으로 상이

## 1. 드라이브 뒷단 배치 (Post-Drive Boost)

- **체인 위치:** `OCD → Suhr Riot → Mooer Pure Boost → Meet Maude → TONEX`

```mermaid
flowchart LR
  IN[기타] --> D["드라이브<br/>(클리핑 완료)"] --> B["부스터<br/>진폭만 ×N"] --> AMP[TONEX]
```

- **작동 원리:**
  - 앞단 [[fulltone-ocd]]·[[suhr-riot]]에서 이미 파형이 깎인(clipped) 신호를 부스터가 수신 → **파형 형태는 유지한 채 전체 진폭(음량)만 선형 증폭**
  - 왜곡의 질감(하모닉스 구성)은 이미 결정된 상태 → 게인감 변화 없음
- **사운드 특성:**
  - 볼륨 증가(Volume Boost) → 디스토션 양·톤 질감 거의 불변, dB만 직관적 상승
  - TONEX 앰프 시뮬 입력단에 헤드룸이 남아 있는 한 → 추가 왜곡 없이 밴드 믹스를 뚫는 솔로 음량 확보
- **추천 용도:**
  - 백킹 → 솔로 전환 시 **음량만 시원하게 부스트**

## 2. 드라이브 앞단 배치 (Pre-Drive Boost)

- **체인 위치:** `Mooer Pure Boost → OCD → Suhr Riot → Meet Maude → TONEX`

```mermaid
flowchart LR
  IN[기타] --> B["부스터<br/>입력 진폭 ↑"] --> D["드라이브<br/>클리핑 극대화"] --> AMP[TONEX]
```

- **작동 원리:**
  - 기타 원신호를 강하게 펌핑하여 뒷단 드라이브 인풋으로 밀어 넣음
  - 클리핑 임계를 초과하는 구간이 늘어남 → 드라이브 자체의 **압축(compression)·왜곡(gain)·서스틴 극대화**
- **사운드 특성:**
  - 게인/새추레이션 증가 → 전체 볼륨은 크게 안 커지는 대신 왜곡 밀도·서스틴 증가
  - 피킹 어택이 쫀득해지고 밀도 상승 → 단, 드라이브 내부 볼륨 노브가 출력을 눌러 실제 음량 체감은 적음
- **추천 용도:**
  - 크런치 → 강한 디스토션 변화, 볼륨보다 **질감·컴프레션 확보**

## 요약 비교

| 항목 | Post-Drive (뒷단) | Pre-Drive (앞단) |
| --- | --- | --- |
| 증폭 대상 | 클리핑된 신호의 진폭 | 클리핑 전 입력 신호 |
| 게인/왜곡 | 거의 불변 | 크게 증가 |
| 음량 체감 | 크게 증가 | 적음 |
| 서스틴 | 불변 | 증가 |
| 주 용도 | 솔로 볼륨 부스트 | 톤 질감·컴프레션 |

## 💡 Tips

- 본 보드는 메인 디스토션 [[suhr-riot]]이 이미 강력 → [[mooer-pure-booster]]는 **드라이브 뒷단 '순수 볼륨 부스터'**로 활용하는 것이 라이브 앙상블 밸런스에 유리
- [[mooer-pure-booster]]는 클린 부스터(클리핑 회로 없음)이므로, 앞단 배치 시에도 부스터 자체 왜곡이 아닌 **뒷단 드라이브의 왜곡을 증폭**하는 구조
