# Dunlop Cry Baby GCB95

> [!info] 한 줄 요약
> 표준 와우(Wah) 페달. 트레들 스윕으로 대역통과 필터 이동. 표현력 있는 필터 스윕용.

## 개요

- 인덕터 기반 대역통과(밴드패스) 필터를 트레들(발판) 각도로 스윕하는 와우 페달
- 발판을 앞뒤로 밟아 공진 주파수 이동 → "와~우" 음색 변화
- **True Bypass 아님(버퍼드/하드와이어 방식)** → Off 상태에서도 신호가 회로를 통과 ([[signal-chain]])
- 배치: 드라이브류 앞단 권장 (드라이브 앞=클래식 보컬형 와우 / 뒤=날카롭고 공격적) ([[fulltone-ocd]], [[suhr-riot]])

## 제원

| 항목 | 값 |
| --- | --- |
| 카테고리 | 와우 (필터) |
| 바이패스 | **버퍼드/하드와이어 (True Bypass 아님)** |
| 전원 | 9V DC / 약 900µA (초저전류) / 센터 네거티브 |
| 어댑터 | Dunlop ECB003 (센터 네거티브) |
| 배터리 | 지원 (9V 1개) |
| 필터 (LowPass) | 350 ~ 450 Hz |
| 필터 (HighPass) | 1.5 ~ 2.5 kHz |
| Max Gain | Heel +19.5dB / Toe +19dB |
| 크기 | 약 249 × 102 × 64 mm (공식 미기재, 통상값·확인 필요) |
| 무게 | 약 1.4 kg (공식 미기재, 통상값·확인 필요) |

## 입출력 단자

| 단자 | 타입 | 용도 |
| --- | --- | --- |
| INPUT | 1/4" TS (800kΩ) | 기타 입력 |
| OUTPUT | 1/4" TS (10kΩ) | 다음 페달 출력 |
| DC IN | 5.5·2.1mm 센터 네거티브 | 전원 (ECB003) |

## 컨트롤

### 노브

> 노브 없음 (스윕은 전적으로 트레들 각도로 제어)

- 별도 노브·트림·DIP 없음 → 필터 스윕은 발판(트레들) 물리 각도로만 조절

### 스위치 / 버튼

| 컨트롤 | 포지션/동작 | 역할 |
| --- | --- | --- |
| 트레들 (발판) | 앞뒤 기울임 | 필터 공진 주파수 스윕 (Heel↔Toe) |
| 풋스위치 | 발끝으로 끝까지 눌러 클릭 | 와우 On/Off (트레들 최전방 하단) |

## 모드 상세

- 단일 모드 페달 (선택 스위치 없음)
- 트레들 위치별 필터 특성

| 트레들 위치 | 필터 상태 | 음색 |
| --- | --- | --- |
| Heel Down (발뒤꿈치, 완전 뒤로) | LowPass 350~450Hz 부근 | 어둡고 먹먹함, +19.5dB |
| 중간 | 대역통과 이동 중 | "와우" 스윕 중간 톤 |
| Toe Down (발끝, 완전 앞으로) | HighPass 1.5~2.5kHz 부근 | 날카롭고 밝음, +19dB |

- 바이패스 특성: 하드와이어/버퍼드 → 다수 True Bypass 페달과 체인 시 톤 로딩 유발 가능
- True Bypass 필요 시 별도 모델 **GCB95F Cry Baby Classic** 존재 (본 GCB95는 해당 없음)

## 주요 톤 셋업 (5종 이상)

> 노브가 없으므로 트레들 각도·주법·배치로 세팅 구성

| # | 톤 명칭 | 트레들 / 배치 | 용도 |
| --- | --- | --- | --- |
| 1 | 클래식 리듬 와카와카 | 중간 각도에서 리드미컬 스윙 | 펑크/커팅 리듬 |
| 2 | 리드 보컬 와우 | 드라이브 앞단, 스윕 넓게 | 솔로 표현력 강조 |
| 3 | 콕트 와우 (고정 와우) | Toe 근처 반쯤 고정 | 미드 강조 필터 톤 |
| 4 | 어그레시브 와우 | 드라이브/디스토션 뒤단 배치 | 날카로운 메탈 와우 |
| 5 | 슬로우 스윕 | 발판 천천히 왕복 | 앰비언트/사이키델릭 |

## 사용 경험 / 특이사항

- **True Bypass 아님** → Off 시에도 신호가 버퍼/회로 통과, 다른 True Bypass 페달과 조합 시 로딩 유의
- 소비 전류 약 900µA로 극히 낮음 → 파워 서플라이 부담 적음
- 노브·프리셋 없는 순수 물리 트레들 조작 → 발 컨트롤 숙련도가 톤 결정
- 배터리 교체 시 하판 개방 필요
