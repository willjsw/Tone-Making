# DigiTech Whammy

> [!info] 한 줄 요약
> 트레들(익스프레션) 기반 실시간 피치 시프트 페달. Whammy 벤딩 / Harmony / Detune 3계열.

## 개요

- 내장 익스프레션 페달(트레들)로 실시간 피치 시프트를 제어하는 디지털 피치 페달
- 3계열: **Whammy**(단일 피치 벤딩), **Harmony**(하모니), **Detune**(디튠 코러스)
- **주의: 문서명이 `whammy-2` → 실제 보유 개체가 2세대(1997경)일 가능성** → 본 문서는 최신 5세대 기준으로 작성. **실제 보유 모델 확인 필요** ([[signal-chain]])
- 배치: 통상 체인 앞단(클린 신호 입력 시 트래킹 안정적) 권장

## 제원

| 항목 | 값 (5세대 기준) |
| --- | --- |
| 카테고리 | 피치 시프트 / 익스프레션 |
| 바이패스 | True Bypass (5세대) |
| 전원 | 9V DC / 265mA 이하 (300mA 권장) / 센터 네거티브 |
| 배터리 | 미지원 (DC 전용) |
| 크기 | 165 × 197 × 64 mm |
| 무게 | 약 1.63 kg (포장 포함 기준) |

## 입출력 단자

| 단자 | 타입 | 용도 |
| --- | --- | --- |
| INPUT | 1/4" TS (1MΩ) | 기타 입력 |
| OUTPUT | 1/4" TS (1kΩ) | 다음 페달 출력 |
| MIDI IN | 5핀 DIN | 프리셋/파라미터 MIDI 제어 (5세대) |
| DC IN | 센터 네거티브 | 전원 |

## 컨트롤

### 노브

> 셀렉터는 로터리 방식 (연속 노브 아님)

| 컨트롤 | 역할 | 비고 |
| --- | --- | --- |
| Selector Knob (로터리) | Whammy / Harmony / Detune 이펙트 선택 | 각 계열별 세부 인터벌·모드 선택 |
| 내장 익스프레션 페달 (트레들) | 피치 벤딩량 실시간 제어 | 발판 각도 = 벤딩 정도 |

### 스위치 / 버튼

| 컨트롤 | 포지션/동작 | 역할 |
| --- | --- | --- |
| Classic / Chords 스위치 | 토글 | 단음 알고리즘(Classic) ↔ 화음 대응(Chords) |
| 풋스위치 (Effect On/Off) | 트레들 전방 클릭 | 이펙트 On/Off |
| 롱프레스 부팅 | 풋스위치 누른 채 전원 인가 | MIDI 채널 설정 / 캘리브레이션 모드 진입 |

## 모드 상세

### Whammy 구간 (단일 피치 벤딩)

| 설정 | 벤딩 범위 |
| --- | --- |
| 2 OCT UP | 최대 2옥타브 상행 |
| 1 OCT UP | 1옥타브 상행 |
| 2ND / 4TH / 5TH UP | 각 인터벌 상행 |
| 1 OCT DN | 1옥타브 하행 |
| 2 OCT DN | 2옥타브 하행 |
| DIVE BOMB | 최대 3 OCT DN 급강하 |

### Harmony 구간 (2음 사이 벤딩)

| 설정 (예) | 특성 |
| --- | --- |
| 인터벌 A ↔ 인터벌 B | 두 하모니 인터벌 사이를 트레들로 이동 |
| 예: 3RD > 5TH | 3도 ↔ 5도 하모니 전환 벤딩 |

- 정확한 인터벌 조합 라벨은 로터리 셀렉터 인쇄 기준(개체·세대별 상이 가능) → 확인 필요

### Detune 구간 (디튠 코러스)

| 설정 | 특성 |
| --- | --- |
| SHALLOW | 얕은 디튠 (은은한 코러스감) |
| DEEP | 깊은 디튠 (두꺼운 더블링감) |

### Classic / Chords 스위치

| 포지션 | 처리 | 특성 |
| --- | --- | --- |
| Classic | 단음(모노포닉) 알고리즘 | 빈티지 트래킹, 아티팩트 있음 |
| Chords | 화음 대응 알고리즘 | 코드 벤딩 대응 (5세대 기능) |

## 주요 톤 셋업 (5종 이상)

| # | 톤 명칭 | 셀렉터 / 트레들 | 용도 |
| --- | --- | --- | --- |
| 1 | 옥타브 업 리드 | Whammy 1 OCT UP, 발판 앞 고정 | 리드 옥타브 상행 |
| 2 | 다이브 밤 | Whammy DIVE BOMB, 발판 급하강 | 트레몰로 없는 급강하 이펙트 |
| 3 | 하모니 리드 | Harmony 5TH, 트레블 벤딩 | 트윈 기타 하모니 라인 |
| 4 | 디튠 두께 | Detune SHALLOW | 클린/리듬 두께 보강 |
| 5 | 슬라이드 벤딩 | Whammy 2ND UP, 발판 왕복 | 반음/온음 슬라이드 표현 |

## 사용 경험 / 특이사항

- **실제 보유 모델 확인 필요.** 2세대(1997경)는 다음 미지원:
  - Classic / Chords 스위치 없음
  - MIDI 미지원
  - 화음(Chords) 알고리즘 없음
- 5세대 기준 True Bypass, 그러나 세대별 바이패스 방식 상이 → 개체 확인 권장
- 소비 전류가 높은 편(265mA↓) → 아이솔레이티드 300mA 이상 출력 권장
