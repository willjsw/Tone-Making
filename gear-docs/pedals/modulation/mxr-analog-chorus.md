# MXR M234 Analog Chorus

> [!info] 한 줄 요약
> BBD(Bucket-Brigade) 아날로그 코러스. Low/High 톤 셰이핑 + THRU OUT 스테레오 지원.

## 개요

- BBD 소자 기반 올아날로그 코러스 → 따뜻하고 유기적인 변조음
- Low / High 2밴드 톤 컨트롤로 코러스 대역 정밀 조절 → 저역 뭉침·고역 쏘임 억제
- OUT 2개(Mono OUT + THRU OUT) → 스테레오 확장 가능 ([[signal-chain]])
- 모드 셀렉터·프리셋 없음 → 단일 코러스 톤 특화

## 제원

| 항목 | 값 |
| --- | --- |
| 카테고리 | 모듈레이션 / 코러스 |

| 전원 | 9V DC / 13mA / 센터 네거티브 (표준 5.5·2.1mm, 극성 확인 필요) |

## 입출력 단자

| 단자 | 타입 | 용도 |
| --- | --- | --- |
| INPUT | 1/4" TS (1MΩ) | 기타 입력 |
| OUTPUT (Mono) | 1/4" TS (1kΩ) | 모노 출력 / 메인 출력 |
| THRU OUT | 1/4" TS (1kΩ) | 스테레오 확장용 두 번째 출력 |
| DC IN | 5.5·2.1mm 센터 네거티브 | 전원 |

### THRU OUT 스테레오 동작

- Mono OUT: 코러스가 걸린 웻(wet) 신호 출력
- THRU OUT: 드라이(dry) 신호 또는 위상 분리된 신호 출력 → 두 앰프로 분배 시 넓은 스테레오 이미지 형성
- 모노 사용 시: Mono OUT 단독 사용 → THRU OUT 미연결
- 스테레오 사용 시: Mono OUT → 앰프 A, THRU OUT → 앰프 B ([[signal-chain]])

> THRU OUT의 정확한 신호 특성(순수 dry 여부·위상 관계)은 공식 매뉴얼 확인 필요

| 노브 | 7시(0%) | 12시(50%) | 5시(100%) | 역할 |
| --- | --- | --- | --- | --- |

| Rate | 가장 느림 | 12시, 50% | 가장 빠름 | LFO 변조 속도 |
| Depth | 미세 변조 | 12시, 50% | 극단적 변조 | 변조 깊이(피치 변조 폭) |
| Low | 저역 컷 최대 | 12시, 50% | 저역 통과(flat) | 코러스 저역 셰이핑 (약 70Hz~800Hz, 12dB/oct) |
| High | 고역 컷 최대 | 12시, 50% | 고역 통과(flat) | 코러스 고역 셰이핑 (약 660Hz~flat, 6dB/oct) |

> Low/High 대역·감쇄량 수치는 참고값 → 공식 확인 필요

## 모드 상세

- 단일 코러스 모드 → 별도 모드 전환 없음
- Low/High 톤 컨트롤로 사운드 캐릭터 조정: 어둡고 두툼한 빈티지 코러스 ~ 밝고 찰랑이는 모던 코러스

## 사용 경험 / 특이사항

- BBD 아날로그 특유의 따뜻하고 부드러운 변조 → 디지털 코러스 대비 유기적
- Low/High 컨트롤 덕분에 저역 뭉침 없이 드라이브 뒷단 배치 가능
- Buffered 바이패스 → 체인 내 신호 유지 유리
- 스테레오 확장 시 THRU OUT 필수 → 모노 리그에선 미사용
