# Boss DD-7

> [!info] 한 줄 요약
> 2-in/2-out 스테레오 디지털 딜레이. 최대 6.4초 · HOLD 루퍼 · Analog/Modulate/Reverse 모드. Tap Tempo 지원.

## 개요

- BOSS 컴팩트 디지털 딜레이, 스테레오 입출력 지원
- 최대 6.4초 딜레이, HOLD(루프 40초), Analog·Modulate·Reverse 특수 모드 내장
- TONEX 뒷단 배치 → 앰프단 이후 깨끗한 반복음 형성 ([[signal-chain]])
- 페달 롱프레스로 Tap Tempo, 외부 EXP/풋스위치 확장 가능

## 제원

| 항목 | 값 |
| --- | --- |
| 카테고리 | 디지털 딜레이 (스테레오) |
| 바이패스 | Buffered (seamless switching, 오프 후 잔향 자연 감쇠) |
| 전원 | 9V DC / 60mA / 센터 네거티브 (매뉴얼 명시) |
| 배터리 | 지원 (9V 6LR61, 약 6시간) |
| 최대 딜레이 | 6.4초 (롱 딜레이 연결 시) |

## 입출력 단자

| 단자 | 타입 | 용도 |
| --- | --- | --- |
| INPUT A (MONO) | 1/4" | 메인 입력 (잭 = 전원 스위치 겸용) |
| INPUT B | 1/4" | 스테레오 입력 |
| OUTPUT A (MONO) | 1/4" | 메인 출력 |
| OUTPUT B | 1/4" | 스테레오 출력 |
| TEMPO / EXP | 1/4" | 외부 풋스위치(FS-5U) 또는 익스프레션(EV-5) |
| DC IN | 센터 네거티브 | 전원 |

## 컨트롤

### 노브

> 노브 표기: 7시(0%) ~ 12시(50%) ~ 5시(100%)

| 노브 | 역할 | 비고 |
| --- | --- | --- |
| E.LEVEL | 이펙트 음 볼륨 | 3시 = 다이렉트와 동일 레벨 (REVERSE 시 MAX면 이펙트음만) |
| F.BACK | 피드백(반복 수) | HOLD 모드에서 무효 |
| D.TIME | 딜레이 타임 | HOLD 모드에서 무효 |
| MODE | 딜레이 모드 셀렉터 (로터리) | 아래 표 |

### 풋스위치 동작

| 조작 | 동작 |
| --- | --- |
| 밟기 | 이펙트 On/Off |
| 2초 이상 롱프레스 | TEMPO 모드 진입 (CHECK 녹색) → 곡 템포로 탭 → 다시 2초로 확정 |
| (HOLD 모드) 밟기 | 녹음 시작 → 재생 |
| (HOLD 모드) 재생 중 밟기 | 오버더빙 |
| (HOLD 모드) 2회 연타 | 정지 |

## 모드 상세

### 딜레이 모드 + 타임

| MODE | 딜레이 타임 | 특성 |
| --- | --- | --- |
| 3200ms | 800–3200ms | 롱 딜레이 |
| 800ms | 200–800ms | 표준 |
| 200ms | 50–200ms | 슬랩백~짧은 반복 |
| 50ms | 1–50ms | 더블링/코러스성 |
| HOLD | 최대 40초 루프 (스테레오 입력 시 20초) | 오버더빙(사운드 온 사운드) |
| MODULATE | 20–800ms | 딜레이음에 코러스 부가 |
| ANALOG | 20–800ms | DM-2 아날로그 딜레이 모델링 (반복마다 음색 열화) |
| REVERSE | 300–3200ms | 역재생 효과 |

- 롱 딜레이 연결 시 각 값 2배 (예: 3200ms 모드 → 1600–6400ms)

### 스테레오 모드 (3종, 전원 꺼도 유지)

| 모드 | 특성 |
| --- | --- |
| 3200ms | A/B 독립 딜레이 |
| 800ms | 패닝 딜레이 |
| 200ms | 공간 확장 스테레오 |

### 확장 제어

- Tap Tempo 범위: 0.2–3.2초 (롱 6.4초), HOLD 모드에서는 탭 불가
- 외부 FS-5U 연결 시 그것으로 탭 (모드별 4분/점8분/8분/3연음 변환)
- EV-5 연결 시 E.LEVEL / F.BACK / D.TIME 원격 제어 (최댓값만 설정)

## 사용 경험 / 특이사항

- INPUT A에 케이블 꽂아야 전원 인가 (미연결 시 전원 차단)
- Buffered 바이패스 → 오프해도 마지막 반복음 자연 감쇠(트레일)
- 일반 프리셋 저장 없음 (스테레오 모드·EXP 설정만 유지)
