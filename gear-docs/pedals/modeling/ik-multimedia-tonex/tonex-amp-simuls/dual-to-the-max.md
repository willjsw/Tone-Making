# Dual to the Max (Mesa/Boogie Dual Rectifier)

> [!info] 한 줄 요약
> 뉴메탈의 상징, Mesa Dual Rectifier의 거대한 저음과 스쿱 미드 헤비 디스토션 캡처.

## 개요

- Tone Model 명 `Dual to the Max` → 캡처명은 ToneNET 제작자 별칭, 기반 앰프는 **추정**임
- 별칭 "Dual"은 Dual Rectifier를 직접 지시하는 것으로 추정
- Mesa/Boogie Dual Rectifier = 90년대 뉴메탈/모던메탈의 사운드 정의 앰프
- 특징: 압도적 저음, 스쿱된 미드, 공격적 어택
- 대표 사용: Limp Bizkit, Korn, Metallica("Black Album" 이후), Dream Theater 등

## 원본 앰프 제원·특성

| 항목 | 값 |
| --- | --- |
| 제조 | Mesa/Boogie (미국) |
| 출력 | 100W (Dual Rectifier 기준) |
| 채널 | 3채널 (Clean / Vintage / Modern) *리비전별 상이* |
| 파워관 | 6L6 (또는 EL34 스왑 가능) |
| 정류 | 튜브/실리콘 정류 선택 (Rectifier) |
| EQ 성향 | 강한 저음 + 스쿱 미드 + 거친 상단 |
| 게인 구조 | Modern 채널 초고게인, "Silicon Diode + Bold" 시 타이트·펀치 |

## 톤 성향

- 거대한 저음 우퍼감 → 헤비 리프의 벽
- 미드 스쿱 → "V자" 스쿱 톤, 뉴메탈 특유
- 공격적 어택·팜뮤트 처크(chug)
- 게인 과다 시 저음 뭉침 → 게이트·타이트닝 필수

## TONEX 세팅 가이드

| 파라미터 | 방향 | 비고 |
| --- | --- | --- |
| Gain | 중고~고 | 과다 시 저음 붕괴 → 노이즈 게이트 병행 |
| Bass | 중~중상 | 이미 저음 큼, 과다 금지 |
| Mid | 중하 | 스쿱 톤 → 필요 시 살짝만 |
| Treble | 중~중상 | 어택·처크 명료도 |
| Presence | 중상 | 거친 상단·공격성 |

## 이 시뮬로 만드는 주요 톤

- 뉴메탈 헤비 리프 (Limp Bizkit 스타일)
- 스쿱 미드 다운튜닝 처그
- 공격적 팜뮤트 리듬
