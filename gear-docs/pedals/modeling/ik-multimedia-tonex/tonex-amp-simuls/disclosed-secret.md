# Disclosed Secret (EVH 5150 III Stealth)

> [!info] 한 줄 요약
> EVH 5150 III Stealth의 화사한 하이미드 모던 하이게인, J-Rock 리드에 최적 캡처.

## 개요

- Tone Model 명 `Disclosed Secret` → 캡처명은 ToneNET 제작자 별칭, 기반 앰프는 **추정**임
- 동일 계열 솔로용 캡처 `High Value Secret` 별도 존재 (게인·상단 더 화사, 솔로 부각용)
- EVH 5150 III = Eddie Van Halen 시그니처, Stealth(100S)는 올블랙 코스메틱 특별판
- 특징: 화사한 하이미드, 매끈한 서스테인, 타이트 저음, 현대적 정의감
- 대표 사용: 모던 록/메탈, J-Rock 리드 (SPYAIR 등 밴드 사운드 계열)

## 원본 앰프 제원·특성

| 항목 | 값 |
| --- | --- |
| 제조 | EVH / Fender (미국) |
| 모델 | 5150 III 100S (Stealth) |
| 출력 | 100W |
| 채널 | 3채널 (Clean / Crunch / Lead), 각 독립 Vol·Gain·Presence·Low·Mid·High |
| 파워관 | 6L6 ×4 |
| 프리관 | JJ ECC83 ×8 |
| 추가 | 채널별 후면 Resonance(저음) 조절, 임피던스 4/8/16Ω 스위치 |
| EQ 성향 | 화사한 하이미드, 매끈한 상단, 타이트 저음 |
| 게인 구조 | 채널 3(Lead) 초고게인·긴 서스테인, 채널 2(Crunch)는 로우미드 정의 개선 |

> [!note] 확인 필요
> "Stealth"는 코스메틱 특별판 명칭이며 회로적으로 5150 III 100W 6L6과 동일 계열. 캡처가 정확히 어느 채널 기반인지는 ToneNET 확인 필요.

## 톤 성향

- 화사하고 밝은 하이미드 → 밴드 믹스에서 리드 라인 잘 뚫림
- 매끈한 게인 텍스처 → 레가토·속주 부드러움
- 타이트 저음 → 리듬도 커버 가능
- 5150 계열 특유의 "현대적이고 정돈된" 하이게인

## TONEX 세팅 가이드

| 파라미터 | 방향 | 비고 |
| --- | --- | --- |
| Gain | 중고~고 | Lead 채널 성향, 서스테인 확보 |
| Bass | 중 | 타이트 유지 |
| Mid | 중~중상 | 5150 특유 하이미드 존재감 |
| Treble | 중상 | 화사한 상단 |
| Presence | 중상 | 리드 투명도·어택 |

> [!tip] 솔로 전환
> 솔로 시 `High Value Secret` 캡처 또는 Gain/Presence 상향 + Delay 추가로 부각
