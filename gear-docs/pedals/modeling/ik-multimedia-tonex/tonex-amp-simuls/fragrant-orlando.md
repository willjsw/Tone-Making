# Fragrant Orlando (Roland JC-120 Jazz Chorus)

> [!info] 한 줄 요약
> 솔리드스테이트 투명 클린의 대명사, Roland JC-120의 유리같은 클린 + 내장 코러스 캡처.

## 개요

- Tone Model 명 `Fragrant Orlando` → 캡처명은 ToneNET 제작자 별칭, 기반 앰프는 **추정**임
- Roland JC-120 (Jazz Chorus) = 1975년 출시 솔리드스테이트 클린 앰프의 표준
- 특징: 헤드룸 넓은 투명 클린, 절대 안 뭉개지는 밝은 톤, 상징적 내장 스테레오 코러스
- 대표 사용: The Police(Andy Summers), Metallica(클린), Robert Smith, K-pop/J-Rock 클린 백킹 다수

## 원본 앰프 제원·특성

| 항목 | 값 |
| --- | --- |
| 제조 | Roland (일본) |
| 방식 | 솔리드스테이트 (트랜지스터) |
| 출력 | 120W (60W ×2 스테레오) |
| 스피커 | 12" ×2 |
| 채널 | Channel 1 (일반) / Channel 2 (Effects: 코러스/비브라토·리버브·디스토션) |
| EQ 성향 | 밝고 투명, 강한 상단, 스크래치 없는 클린 |
| 특징 | 내장 스테레오 코러스 (아날로그 BBD, 독특한 넓은 스테레오감) |

## 톤 성향

- 극도로 투명하고 밝은 클린, 하드한 어택에도 크런치 거의 없음
- 넓은 헤드룸 → 이펙트 페달 플랫폼으로 우수
- 상징적 코러스: 깊고 넓은 스테레오 흔들림
- 솔리드스테이트 특유의 "차갑고 유리같은" 캐릭터 → 튜브 클린과 대비

## TONEX 세팅 가이드

| 파라미터 | 방향 | 비고 |
| --- | --- | --- |
| Gain | 낮음 | 클린 유지, 브레이크업 최소 |
| Bass | 중 | 저음 과다 시 둔탁 |
| Mid | 중~중하 | 투명감 위해 미드 억제 가능 |
| Treble | 중상 | JC 특유 밝은 상단 |
| Presence | 중상 | 유리같은 반짝임 강조 |

> [!tip] 코러스
> 원본의 상징적 코러스는 TONEX MODULATION(chorus)으로 재현 → 넓게·깊게
