# Wrong Input (Marshall JCM 800)

> [!info] 한 줄 요약
> Marshall JCM 800 (2203/2204)의 미드 강조 브리티시 크런치, 록의 원형 톤 캡처.

## 개요

- Tone Model 명 `Wrong Input` → 캡처명은 ToneNET 제작자 별칭, 기반 앰프는 **추정**임
- 별칭 "Input"은 JCM 800의 High/Low 감도 인풋 잭을 지시하는 것으로 추정
- Marshall JCM 800 (2203 100W / 2204 50W) = 80년대 하드록·메탈의 표준, 심플회로 마스터볼륨 싱글채널의 마지막 세대
- 특징: 공격적 어퍼미드, 타이트 저음, 퍼지지 않고 무는(bite) 상단
- 대표 사용: AC/DC(Angus Young), Slayer, Zakk Wylde, Kerry King, 브리티시 록 광범위

## 원본 앰프 제원·특성

| 항목 | 값 |
| --- | --- |
| 제조 | Marshall (영국) |
| 모델 | 2203 (100W) / 2204 (50W) |
| 방식 | 올튜브, 싱글채널 마스터볼륨 |
| 파워관 | EL34 |
| 컨트롤 | Preamp Vol · Bass · Middle · Treble · Presence · Master Volume |
| 인풋 | High / Low 감도 인풋 (2잭) |
| EQ 성향 | 공격적 어퍼미드, 타이트 저음, 무는 상단 |
| 게인 구조 | 플렉시와 모던 하이게인 사이, 마스터볼륨으로 저볼륨 새추레이션 |

## 톤 성향

- 강조된 어퍼미드 → 믹스를 뚫는 록 크런치의 정의
- 타이트 저음 → 파워코드·리프 명료
- 상단은 물되(bite) 퍼지지(fizz) 않음
- 부스트 페달(오버드라이브) 앞단 조합 시 하이게인 리드까지 확장 (마샬 정석 조합)

## TONEX 세팅 가이드

| 파라미터 | 방향 | 비고 |
| --- | --- | --- |
| Gain | 중~중고 | 크런치 코어, 리드는 앞단 부스트 병행 |
| Bass | 중 | 타이트 유지 |
| Mid | 중상~상 | JCM 800 핵심, 미드 밀어 올림 |
| Treble | 중상 | 무는 상단 |
| Presence | 중상 | 어택·공격성 |

## 이 시뮬로 만드는 주요 톤

- 브리티시 록 크런치 리듬
- 미드 강조 파워코드 리프
- 부스트 병행 클래식 하드록 리드/솔로
