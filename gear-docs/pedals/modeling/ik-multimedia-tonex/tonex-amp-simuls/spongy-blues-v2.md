# Spongy Blues v2 (Fender '65 Deluxe Reverb)

> [!info] 한 줄 요약
> Fender '65 Deluxe Reverb의 빈티지 클린~쫀득 엣지오브브레이크업, 스프링 리버브 캡처.

## 개요

- Tone Model 명 `Spongy Blues v2` → 캡처명은 ToneNET 제작자 별칭, 기반 앰프는 **추정**임
- 별칭 "Spongy(쫀득)/Blues"는 Deluxe Reverb의 낮은 헤드룸에서 오는 컴프레션감·브레이크업을 지시하는 것으로 추정
- Fender '65 Deluxe Reverb = 블랙페이스 시대의 상징, 22W 낮은 헤드룸 → 볼륨 올리면 자연스러운 크런치
- 특징: 빈티지 클린, 낮은 볼륨에서도 브레이크업, 상징적 스프링 리버브 + 비브라토
- 대표 사용: 블루스/루츠/인디/컨트리 광범위

## 원본 앰프 제원·특성

| 항목 | 값 |
| --- | --- |
| 제조 | Fender (미국) |
| 방식 | 올튜브 (블랙페이스 회로) |
| 출력 | 22W |
| 스피커 | 12" ×1 |
| 파워관 | 6V6 ×2 |
| 채널 | Normal / Vibrato (Reverb·Vibrato는 Vibrato 채널) |
| EQ 성향 | 따뜻한 미드, 스무스한 상단, 블랙페이스 특유 균형 |
| 게인 구조 | 낮은 헤드룸 → 볼륨 6~7부터 쫀득한 자연 브레이크업 |
| 내장 이펙트 | 스프링 리버브 + 튜브 비브라토(트레몰로) |

## 톤 성향

- 낮은 볼륨 클린은 따뜻·둥글, 볼륨 올리면 쫀득(spongy) 컴프레션 브레이크업
- 파워관 6V6 특유의 부드러운 새그(sag)·다이나믹
- 상징적 스프링 리버브 → 서프·루츠·블루스 필수
- 픽 어택·볼륨 노브에 극도로 반응적 (touch-sensitive)

## TONEX 세팅 가이드

| 파라미터 | 방향 | 비고 |
| --- | --- | --- |
| Gain | 낮음~중 | 엣지오브브레이크업 지점 탐색 |

| Mid | 중~중상 | 블랙페이스 미드 온기 |
| Treble | 중상 | 스무스한 상단 반짝임 |
| Presence | 중 | 과다 시 날카로움 |
