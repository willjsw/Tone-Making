# TONEX 앰프 시뮬 (프리셋 사용분)

> [!info] 한 줄 요약
> 현재 [[INDEX|프리셋]]에 실제 사용 중인 TONEX Tone Model(캡처)만 정리. 캡처명은 ToneNET 제작자 명명, 기반 앰프는 추정.

> [!note] 명명 규칙
> TONEX Tone Model 이름(예: `Third Gain`)은 ToneNET 캡처 제작자가 붙인 별칭 → 원본 앰프는 캡처 설명·톤 특성 기반 **추정**. 실제 캡처 상세는 ToneNET에서 확인 필요.
