# Third Gain (Diezel VH4)

> [!info] 한 줄 요약
> 독일 Diezel VH4의 타이트하고 정의감 높은 프로그레시브 하이게인 캡처.

## 개요

- Tone Model 명 `Third Gain` → 캡처명은 ToneNET 제작자 별칭, 기반 앰프는 **추정**임
- 별칭 "Third"는 VH4의 3번 채널(Mega/Heavy) 기반으로 추정
- Diezel VH4 = 독일산 100W 4채널 올튜브 헤드, 90년대부터 메탈/프로그레시브의 표준 하이게인
- 특징: 극단적 게인에서도 흐트러지지 않는 노트 분리감(definition), 타이트한 저음
- 대표 사용: Tool, Metallica, Muse, Adam Jones 등

## 원본 앰프 제원·특성

| 항목 | 값 |
| --- | --- |
| 제조 | Diezel (독일) |
| 출력 | 100W |
| 채널 | 4채널 (Clean / Crunch / Mega(Heavy) / Lead) |
| 파워관 | EL34 ×4 (또는 KT77) |
| 프리관 | 12AX7 |
| 채널별 컨트롤 | 각 채널 독립 Gain·Bass·Mid·Treble·Master |
| EQ 성향 | 넓은 대역, 강한 저음 컨트롤 + 선명한 상단 |
| 게인 구조 | 채널 3(Mega) 타이트 하이게인 → 채널 4(Lead) 더 압축·더 저음·크리미한 상단 |

## 톤 성향

- 하이게인에서도 코드 노트 분리 명확 → 다운튜닝/속주 리프에 강함
- 저음 타이트 → 뭉개짐 없는 팜뮤트
- 상단 선명하되 거칠지 않음 → 리드 서스테인 부드러움
- 미드 스쿱 계열(Recto)과 대비되는 "미드 존재감 있는" 하이게인

## TONEX 세팅 가이드

| 파라미터 | 방향 | 비고 |
| --- | --- | --- |
| Gain | 중~중고 | 캡처 자체 게인 높음 → 과증폭 주의 |
| Bass | 중 | 타이트 유지, 과다 시 저음 뭉침 |
| Mid | 중~중상 | VH4 특유의 미드 존재감 살림 |
| Treble | 중 | 선명도 확보 |
| Presence | 중~중상 | 리프 어택·리드 투명도 |

## 이 시뮬로 만드는 주요 톤

- 프로그레시브 메탈 리드 (Tool 스타일)
- 타이트 다운튜닝 리프
- 서스테인 긴 하이게인 솔로
