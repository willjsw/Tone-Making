# Polite Twin (Fender Twin Reverb '65)

> [!info] 한 줄 요약
> Fender Twin Reverb '65의 넓은 헤드룸 클린과 밝고 청량한 톤, 클린 백킹의 기준 캡처.

## 개요

- Tone Model 명 `Polite Twin` → 캡처명은 ToneNET 제작자 별칭, 기반 앰프는 **추정**임
- 별칭 "Twin"은 Twin Reverb를 직접 지시하는 것으로 추정
- Fender Twin Reverb '65 = 블랙페이스 클린의 최고봉, 85W 대출력으로 극단적으로 넓은 헤드룸
- 특징: 크게 틀어도 안 뭉개지는 라우드 클린, 밝고 명료한 상단, 상징적 스프링 리버브·비브라토
- 대표 사용: 컨트리·재즈·펑크·팝·인디 클린 백킹 전방위

## 원본 앰프 제원·특성

| 항목 | 값 |
| --- | --- |
| 제조 | Fender (미국) |
| 방식 | 올튜브 (블랙페이스 회로) |
| 출력 | 85W |
| 스피커 | 12" ×2 |
| 파워관 | 6L6 ×4 |
| 채널 | Normal / Vibrato (Reverb·Vibrato는 Vibrato 채널) |
| EQ 성향 | 밝고 명료, 넓은 대역, 균형 잡힌 블랙페이스 톤 |
| 게인 구조 | 대출력 → 매우 높은 클린 헤드룸, 브레이크업 늦음 |
| 내장 이펙트 | 스프링 리버브 + 튜브 비브라토(트레몰로) |

## 톤 성향

- 넓은 헤드룸 → 높은 볼륨에서도 크리스탈 클린 유지
- 밝고 청량한 상단, 명료한 어택
- Deluxe Reverb 대비 브레이크업 훨씬 늦고 더 라우드·더 하이파이
- 이펙트 플랫폼으로 최상 (페달 반응 깨끗)

## TONEX 세팅 가이드

| 파라미터 | 방향 | 비고 |
| --- | --- | --- |
| Gain | 낮음 | 클린 헤드룸 유지 |
| Bass | 중 | 저음 풍부, 과다 시 둔탁 |
| Mid | 중~중하 | 청량감 위해 미드 억제 가능 |
| Treble | 중상 | 밝은 상단 |
| Presence | 중상 | 청량한 반짝임·명료도 |

> [!tip] 리버브/비브라토
> 원본 스프링 리버브는 TONEX REVERB(SPRING) + MODULATION(tremolo)로 재현

## 이 시뮬로 만드는 주요 톤

- 라우드 크리스탈 클린 백킹
- 밝은 아르페지오·커팅
- 페달 플랫폼 클린 (딜레이/모듈레이션 레이어)
