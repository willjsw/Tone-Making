# Suhr Riot

> [!info] 한 줄 요약
> 릴레이 True Bypass 하이게인 디스토션. Voice 3단 스위치 + FX Link 리모트. 슈게이징~메탈용 메인 디스토션.

## 개요

- 튜브 앰프 라이크한 하이게인 디스토션 페달
- 듀얼 옵앰프(오리지널 4580) + LED 2개 상시 클리핑 + 옵션 다이오드 조합
- Voice 3단 스위치로 EQ·게인 성향 전환 → 크런치부터 과격한 퍼즈성 장벽까지
- 슈게이징/드림팝 등 거친 톤에서 메인 디스토션으로 활용 ([[signal-chain]])

| 항목 | 값 |
| --- | --- |
| 카테고리 | 하이게인 디스토션 |
| 바이패스 | 릴레이 True Bypass (팝 노이즈 최소화) |
| 전원 | 9V DC 센터 네거티브 (4~18V 동작, 정격 9V, 최대 20V) / 약 8mA |
| 배터리 | 지원 (배터리 모니터 내장) |
| 보호 회로 | 역극성 · 과전압 보호 |
| 크기 | 2.50 × 4.50 × 1.25 in |
| 무게 | 약 340g (0.75 lb) |

## 입출력 단자

| 단자 | 타입 | 용도 |
| --- | --- | --- |
| INPUT | 1/4" (1MΩ) | 앞단 입력 |
| OUTPUT | 1/4" (600Ω) | 다음 페달 출력 |
| FX Link | 1/8" 모노 (최대 3.3V) | 리모트 On/Off 제어 |
| DC IN | 2.1·5.5mm 센터 네거티브 | 전원 |

## 컨트롤

### 노브

> 노브 표기: 7시(0%) ~ 12시(50%) ~ 5시(100%)

| 노브 | 역할 | 비고 |
| --- | --- | --- |
| Distortion (Dist) | 게인량 | 클래식 크런치 → 하이게인 |
| Level | 출력 레벨 | 최종 음량 |
| Tone | 전체 톤 | CCW = 따뜻·부드러움, CW = 컷팅 리드 |

### 스위치

| 컨트롤 | 포지션 | 역할 |
| --- | --- | --- |
| Voice 3단 토글 | Left / Middle / Right | EQ·클리핑 특성 전환 (아래 상세) |
| FX Link 슬라이드 | — | 전원 인가 시 On/Off/리모트 상태 결정 |

### 배터리 모니터

| 배터리 전압 | 동작 |
| --- | --- |
| 4.5V 이하 | 활성화 시 LED 3회 점멸 (경고) |
| 4V 미만 | 자동 True Bypass 전환 |

## 모드 상세

### Voice 3포지션 (오리지널 Riot)

| 포지션 | 특성 |
| --- | --- |
| Left | 내추럴·유기적 톤, 기타 볼륨에 다이내믹 반응 |
| Middle | 하이게인, 단단한 미드레인지 + 타이트한 저역 |
| Right | 빈티지 하이게인 응답, 뛰어난 디피니션 |

- 낮은 게인·톤 세팅에서는 Voice 효과가 약해질 수 있음
- 포지션별 정확한 클리핑 소자 전환 방식은 공식 문서에 음색 기준으로만 서술 → 회로 상세 확인 필요

### 클리핑 회로

- 듀얼 옵앰프 2개(오리지널 4580) 기반
- 상시 클리핑 LED 2개 + 옵션(비대칭 1N4148 3개 또는 1N34 4개 직렬) 조합

### Riot vs Riot Reloaded (참고)

| 구분 | Riot (오리지널) | Riot Reloaded |
| --- | --- | --- |
| 게인 | 기준 | +30% (메탈/드롭튜닝 지향) |
| Voice Right | 빈티지 하이게인 | 미드 스쿱 응답 |
| Voice Middle 저역 | 타이트 | 두툼(fat) |
| Tone 회로 | 기준 | 상위 미드 강조 (더 스위트) |

> 본 보드 보유 개체는 프리셋의 노브 구성(Voice/Dist/Tone/Level) 기준 **오리지널 Riot**로 판단.

## 주요 톤 셋업 (5종 이상)

| # | 톤 명칭 | Voice · Dist / Level / Tone | 용도 |
| --- | --- | --- | --- |
| 1 | 슈게이징 장벽 | Left/Middle · Dist 2~3시 / Level 12시 / Tone 1~2시 | 거친 퍼즈성 Wall of Sound (3호선 버터플라이) |
| 2 | 타이트 하이게인 리프 | Middle · Dist 1시 / Level 12시 / Tone 12시 | 메탈 리듬 |
| 3 | 빈티지 리드 | Right · Dist 12시 / Level 1시 / Tone 1시 | 디피니션 있는 솔로 |
| 4 | 다이내믹 크런치 | Left · Dist 10시 / Level 12시 / Tone 11시 | 볼륨 반응 크런치 |
| 5 | 스택 부스트 | Middle · Dist 11시 / Level 1시 / Tone 12시 | 앰프 스택 푸시 |
| 6 | 리모트 운용 | FX Link 연결 · 임의 세팅 | 외부 스위처로 원격 토글 |

## 사용 경험 / 특이사항

- 릴레이 True Bypass → 스위칭 팝 노이즈 최소, 리모트 스위칭/배터리 모니터 지원
- LED 활성 시 청색
- 강력한 메인 디스토션 → [[mooer-pure-booster]]는 게인 추가 없이 뒷단 볼륨 부스터로 운용 ([[booster-pedal-position]])
