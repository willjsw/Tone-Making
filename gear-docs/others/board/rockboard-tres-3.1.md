# RockBoard TRES 3.1 (페달보드)

> [!info] 한 줄 요약
> 경량 알루미늄 오픈슬롯 페달보드(by Warwick). 522×236mm, 1.2kg. 슬롯 사이로 케이블·전원 배선.

## 개요

- 냉간압연 알루미늄 1장 성형 + U자형 보강 브레이스 구조 페달보드
- 오픈슬롯 디자인 → 슬롯 사이로 케이블·마운팅 배선 통과, 하부 파워 서플라이 장착 가능
- 본 보드 전체 시그널 체인 페달 탑재 플랫폼 ([[signal-chain]])

## 제원

| 항목 | 값 |
| --- | --- |
| 카테고리 | 페달보드 (경량 알루미늄) |
| 폭 (Width) | 522 mm (약 20.35") |
| 깊이 (Depth) | 236 mm (약 9.29") |
| 높이 | 37 – 71 mm (고무발 포함) |
| 무게 | 1.2 kg (2.6 lbs) |
| 재질 | 냉간압연 알루미늄 + U자 보강, 블랙 파우더코팅, 용접 이음새 없음 |
| 페달 장착 | 오픈슬롯, 약 5~10개 (페달 크기에 따라) |

## 구성 특징

| 요소 | 내용 |
| --- | --- |
| 슬롯 배선 | 슬롯 사이로 케이블·전원 통과 → 배선 정리 |
| 하부 공간 | 파워 서플라이 하부 장착 가능 |
| LED 마운트 | 우측 RockBoard LED Light 마운팅 홀 (라이트 별매) |
| 케이스 | 기그백 / 플라이트케이스 옵션 |

## 탑재 페달 배치 (본 보드)

- 체인 순서대로 좌→우 배치: [[tc-electronic-polytune-3]] → [[fulltone-ocd]] → [[suhr-riot]] → [[mooer-pure-booster]] → [[fairfield-circuitry-meet-maude]] → [[tonex]] → [[wampler-terraform]] → [[boss-dd-7]] → [[neunaber-immerse]]
- TONEX(176×142mm)가 최대 면적 → 배치 시 공간 우선 확보 필요

## 사용 경험 / 특이사항

- 1.2kg 경량 → 이동성 우수
- 오픈슬롯 구조상 벨크로 또는 마운팅 브래킷으로 페달 고정
- 페달 수(9개) 대비 522mm 폭 → 미니 페달([[mooer-pure-booster]]) 활용 시 공간 여유
