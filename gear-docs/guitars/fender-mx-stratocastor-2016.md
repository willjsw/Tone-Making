# Fender Stratocaster (MX 시리얼, 2016)

> [!info] 한 줄 요약
> 멕시코 생산(MIM) SSS 스트라토캐스터. 3싱글코일 · 5-way · 빈티지 트레몰로. 본 보드의 메인 기타.

> [!note] 모델 판별
> "Player" 시리즈는 2018년 출시 → 2016 MX 시리얼 개체는 **Standard Stratocaster (MIM, Ensenada)**로 판단. 21프렛 + 6-Saddle 빈티지 트레몰로가 판별 포인트. 정확한 생산연도는 MX 시리얼 조회 권장(확인 필요).

## 개요

- Made in Mexico(Ensenada) 생산 스탠다드 스트라토캐스터
- SSS(싱글×3) 픽업 구성 → 밝고 투명한 벨류 톤, 넓은 다이내믹
- 5-way 셀렉터로 5가지 픽업 조합 → 곡·파트별 음색 대응
- 모든 프리셋의 기준 기타 ([[signal-chain]])

## 톤 메이킹 고려 특성

- **싱글코일 특성:** 낮은 출력 → 드라이브 페달에 여유 헤드룸, 피킹 다이내믹 예민. 60Hz 험 노이즈에 취약 → 하이게인 시 [[tonex]] Noise Gate 필요
- **브릿지 픽업:** 고역 강조 → 리드/리프에서 [[fulltone-ocd]] Tone·[[suhr-riot]]와 결합 시 날카로움 제어 필요
- **넥 픽업:** 두툼함 → 탭핑·솔로에서 픽업 전환 활용 (SPYAIR 인트로 탭핑 시 넥 전환)
- **빈티지 트레몰로:** 6-Saddle → 아밍 시 미세 피치 흔들림, 튜닝 안정성 위해 [[tc-electronic-polytune-3]] 상시 점검
- **스케일 25.5":** 길고 타이트한 저음 텐션 → 드롭 튜닝·하이게인 리프에 유리

## 사용 경험 / 특이사항

- MX 시리얼 = Made in Mexico, 첫 2자리 이후 연도 코드로 생산연도 추정
- SSS 구성상 하이게인에서 험 노이즈 관리가 관건 → 게이트 세팅 중요
- 21프렛 사양 → 하이 포지션 접근성은 22프렛 대비 제한
